# Prompts para ChatGPT — Imágenes de referencia de personajes (PILO STUDIO)

**Cómo usarlo:**
1. Abre un chat nuevo en ChatGPT por marca y adjunta la guía visual de esa marca.
2. Pega el **PROMPT MAESTRO** una vez.
3. Pide cada personaje con su línea: `Character: ...`. Una imagen por personaje.
4. Guarda cada resultado como `references/<MARCA>/<PERSONAJE>/ref_01.png` y mándamelo.

---

## PROMPT MAESTRO (pegar primero)

```
I'm attaching my official visual production guide. Create a clean CHARACTER REFERENCE image for each character I ask for, one image per message, matching the guide's style EXACTLY.

Rules for every image:
- 2D flat vector neon illustration, minimalist editorial stickman style (same style as the guide).
- Solid pure black background (#000000), nothing else in the background.
- Character body is solid black with a glowing neon outline in its official color; white expressive eyes; simple face.
- Full body, front view, centered, standing, Neutral/Happy expression, relaxed pose (arms slightly away from the body so hands are visible).
- Show ALL official accessories clearly. Keep proportions identical to the guide.
- Square 1:1, high resolution (at least 1024x1024), character fills about 80% of the height.
- ABSOLUTELY NO text, letters, names, labels, numbers, logos, frames, borders or panels.
- No 3D, no realistic rendering, no extra objects, no other characters.
```

## Opcional: hoja de expresiones (mejora mucho la continuidad)
Para cada personaje principal (BLUE, ORANGE, CYAN), después de su referencia:
```
Now create an expression sheet of this SAME character: a 4x3 grid of head-and-shoulders portraits showing, in this order: neutral, happy, talking, surprised, confused, thinking, concerned, skeptical, excited, angry, serious, smug. Same black background, same neon style, NO labels, NO text, NO numbers, no borders between cells.
```
Guárdala como `references/<MARCA>/<PERSONAJE>/expresiones_01.png`.
