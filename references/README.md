# Imágenes de referencia

Coloca aquí las imágenes oficiales de cada personaje para mantener la continuidad visual:

```
references/FACT_STICK/BLUE/front.png
references/FACT_STICK/RICH/front.png
references/WILD_MONEY/PURPLE/front.png
references/MONEY_HOUSE/CORAL/front.png
...
```

El constructor de prompts las adjunta automáticamente a cada imagen donde aparece ese personaje.
Fondo negro, sin texto. Una pose neutral de cuerpo completo como mínimo por personaje.
